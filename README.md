# Voice Bridge

A real-time multilingual voice translation app supporting Urdu, English, and Arabic.

## Prerequisites

Make sure you have these installed before running the project:

- **Node.js** (v18 or higher) — https://nodejs.org
- **npm** (comes with Node.js)
- **Expo CLI** — install by running: `npm install -g expo-cli`
- **EAS CLI** — install by running: `npm install -g eas-cli`

## Running the Backend

```bash
cd backend
npm install
npm start
```

## Running the Frontend

```bash
cd frontend
npm install
npx expo start
```

Then press `w` for web, `a` for Android emulator, or `i` for iOS simulator.

## Features

- Real-time voice translation (Urdu, English, Arabic)
- Direct 1-on-1 calls
- Group meeting rooms (3-5 participants)
- Bridge Messenger with translation
- Neural voice cloning
- Bluetooth audio support
